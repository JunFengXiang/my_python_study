# 10月30日：CSV读取与线性插值

今天完成：读取两个CSV文件，用两个节点计算五个查询点的预测值和绝对误差。

## Python知识

- `Path(__file__).parent`：当前脚本所在的文件夹，用 `/` 继续拼接路径。
- `with ... as file`：打开文件，用 `file` 操作它，离开缩进块后自动关闭。
- `newline=""`：保留原始换行字符，交给CSV解析器处理，不是删除换行。
- `csv.DictReader(file)`：创建读取器，默认第一行是列名；循环里的每个 `row` 才是字典，值默认是字符串。
- `float()` 转成浮点数，`type()` 查看类型。
- `nodes` 是列表，每个元素是一个节点字典；`append()` 添加元素，`nodes[0]["x"]` 取第一个节点的横坐标。
- `f"{x:.1f}"`：将数值显示为一位小数，格式说明写在花括号里。
- `return` 返回计算结果；`raise ValueError(...)` 主动抛出异常，类似Java的 `throw`。

## 插值与误差

```python
k = (y1 - y0) / (x1 - x0)
y_pred = y0 + k * (x - x0)
loss = abs(y_pred - y_reference)
```

`x` 是查询位置，`y_pred` 是直线的预测值，`y_reference` 只用于最后比较，不传入插值函数。

不能只写 `k * x`，那只适用于经过原点的直线。计算前要检查 `x0 != x1`，避免除以零。
