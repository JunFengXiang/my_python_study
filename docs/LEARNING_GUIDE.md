## 每天的任务边界

每天一个实验目标、2—3个相连的实做步骤，必要时增加一个短检查；通常引入1—2个主要新概念。任务量按能够交付的新能力安排，不能把一个已会的小函数占满整天，也不把所有知识堆进一个大项目。

参考分配：10分钟回顾与预测、15分钟读当天小节、70分钟独立编码、15分钟验证、10分钟记录。核心工作约90分钟（含阅读）；其余用于验证与弹性。时间按难度流动，总计不超过120分钟。

- **核心**：完成当天输入—计算—结果中的新增部分，能运行并解释。
- **进阶**：核心通过且有余量，换一个条件、比较一个方法或进入下一单元；每天最多选一项，不重复同构题凑量。
- **保底**：忙碌时用15—30分钟完成核心中的一个可验证环节，保留代码和卡点，不另做一套简化作业。
- **推进**：代码、实际输出和简短解释足够时就前进。Git尚未提交不等于没完成；缺证据只补一个短变式，不每天完整重发同题。
- **卡住**：独立尝试约20分钟后缩小输入、读报错、查中间量，再使用分层提示；同一缺口连续两次未解，下一次针对它补齐。超时停在可恢复状态，优先删选做。
- **调节**：前三次记录实际耗时、主要卡点和是否借助完整答案。连续两次核心不足60分钟，合并已会内容；连续两次超时，减少当天新概念。第七次左右用未见数据检查迁移。

助手给问题、输入数据、必要接口、验收和分层提示；核心算法与实验判断由学习者完成。每个阶段至少有一次离开示例、换数据的独立检查。

## 正式数据来自文件

正式实验读取独立数据文件。`tests/`可保留能手算的小样例，用于检查正确性；正式输入不得只写在测试文件或主程序变量里。现在的 `grammar/10_27/10_27_test.py` 是已有练习，保留原样，不因目录规范要求重写。

| 位置（用到才创建） | 内容与边界 |
|---|---|
| `data/` | 节点、查询点、矩阵、采样记录或文本；原始输入保持只读 |
| `configs/` | 后期需要时存参数与数据路径；初期不强制配置框架 |
| `numerical/` | 当前课程实验的计算、读写和绘图程序；复用已有函数 |
| `results/` | 由程序生成的预测、误差、汇总表与图片 |
| `tests/` | 小型正常/边界/参考值检查；先用简单断言，用到时再学pytest |

输入准备是任务的一部分：每日卡片必须说明文件实际在哪里、字段是什么、来源是什么。若尚未存在，先提供小型CSV或明确生成步骤，标为“待保存/待生成”，不能假装已经有数据。最初可将任务卡给出的CSV保存成独立文件；随后把生成过程写入脚本，固定参数与种子，生成一次保存后再由实验程序读取。

教学数据使用可核验的已知函数或明确标注的模拟过程，保留函数、区间、参数和参考值来源。没有参考解就只报告能计算的残差等量，不虚构误差。后续真实数据另行处理，不把教学模拟结果称作工厂效果。

## 一组结果贯穿多个工具

前段以插值误差实验为主，穿插一个小型线性代数检查。后段使用带噪拟合衔接模型训练；不为学习每个库另建一个无关项目。

第一次只保存够用的字段，例如 `x,y_pred,y_ref,abs_error`。参数扫描后再引入：

| 表 | 最少字段 | 用途 |
|---|---|---|
| runs | run_id、problem、method、dtype，按需加n/h/seed | 标识一次实验与条件 |
| metrics | run_id、metric、value，按需加status | 保存误差、残差等测量 |
| 训练日志 | run_id、split、step、loss，按需加tokens/seconds | 沿用同一整理与绘图流程 |

缺失、零误差和运行失败分别处理。合并前检查键，汇总后对账。原始结果保留；教学故障样例放副本并标注，不冒充真实实验失败。图必须有明确问题、坐标含义和必要单位；画图从前期就开始，后续再系统学习多图与对数坐标。

## 验收和复现

按当天涉及项检查：输入/来源明确；计算可解释；手算或参考结果通过；关键边界处理明确；表或图回答了问题；换同结构输入或重启进程仍可重跑。笔记只记问题、原因、修改、实际验证和适用范围。

基础结束时应能解释shape/axis/广播/view-copy；独立完成选定数值实验；清洗合并分组可对账；从文件生成图表；换数据重跑。未通过就使用缓冲日和缩减选做，不能按日历自动进入GPT。

模型阶段先固定数据划分，再仅用训练集估计预处理参数；验证集调参，测试集留到最后。文本先按文档/边界划分再切窗口，避免窗口重叠泄漏。先做单batch检查，再正常训练；保存模型、优化器、步数和配置，验证恢复行为。固定种子用于记录与复跑，不承诺跨设备逐位相同。

最后的对照只改一个因素，其他数据、训练预算和评价条件保持一致；报告每次运行和失败，用少量重复描述波动，不宣称统计显著。长训练的等待时间单列，每日主动学习仍限120分钟。
