# MacBook 数据分析学习方法与路线

更新：2026-10-29。本文整理已经确定的学习安排和拟采用的方法，不代表下面的练习已经完成。实际问题、输出和验收依据记在[学习记录](LEARNING_LOG.md)。

## 先做什么

前期在 MacBook 本地完成 Python、NumPy、pandas、Matplotlib 和工程基础，使用本仓库。练习从小数据开始，按 macOS 终端操作；当前不以 CUDA、远程机器或 5080 环境为前置。

每天工作日 60 分钟，周六、周日各 120 分钟。基础阶段目标约 21 个学习单元，顺利时约 3 周、27 小时。单元是学习顺序，不是到了日期就自动过关。

当前仍计入原来的 50 天计划：2026-10-27 至 2026-12-15。基础阶段没有另加在 50 天之前；若以后调整周期，再更新这里。基础验收通过后，转到 5080 和 [llm-from-scratch-lab](https://github.com/JunFengXiang/llm-from-scratch-lab) 做小型 GPT 实践。

## 这次确定的学习方法

1. **先预测，再运行。** 数组先写出 shape、axis 和输出；表格操作先判断行数、键和统计含义。用能手算的小样本检查。
2. **每天只解决一个主要问题。** 读当天需要的小节，然后自己实现。已经会的内容用一个变式确认后跳过，不反复从头开始。
3. **把工程习惯放进练习。** 说明输入输出、避免意外修改输入、检查边界、记录依赖和参数、保存真实结果。先把一个小流程做扎实。
4. **用同一个项目反复练。** 从纯 Python 统计开始，逐步加入数组、表格、绘图和重跑入口，减少换题和搭环境的时间。
5. **区分生成材料与学会。** 助手准备的说明和检查只是材料；用户自己的代码、实际输出和解释才是验收依据。看过课程、收到任务卡都不等于掌握。
6. **记录错误怎样解决。** 经验至少包含问题、原因、修改、验证和适用范围，避免只记一串 API 或“今天学了 pandas”。

以上是本次选定的方法；是否适合当前节奏，要通过后续学习记录调整。

## 贯穿项目：实验日志分析器

先使用明确标注为“教学模拟”的 20—100 行小数据，从极小子集开始，逐课增加功能。

| 数据表 | 建议字段 |
|---|---|
| metrics | run_id、step、split、loss、tokens、seconds |
| runs | run_id、seed、learning_rate、batch_size |

模拟数据不代表真实训练结果，不能据此评价模型优劣。以后用自己的真实训练日志替换，继续复用分析代码。

流程逐步形成：读取 → 检查 → 清洗 → 合并 → 分组统计 → 绘图 → 保存。

最终应有：

- 原始数据与处理后结果分开保存，原始数据不被覆盖。
- 清洗规则、问题数量和处理前后行数。
- 汇总 CSV 和 2—3 张有标题、单位、图例及解释的图。
- 可以从干净进程运行的脚本、必要依赖和运行说明。
- 少量真正能发现问题的检查，例如缺列、重复键、空输入、常数列。

上述是计划产物，目前不据此声称代码、数据或结果已存在。

## 每天怎样做

工作日按 5 分钟回忆、10 分钟精读、35 分钟编码、10 分钟检查记录安排。周末用较完整的时间集成、补欠和复盘，不额外堆多个新主题。忙碌时完成一个 15 分钟最小版本即可。

每次保留一个待完成核心练习。提交代码或 commit、实际输出、两句解释后判断是否推进；没有 GitHub 提交不等于没有在本地学习，也可以先提供输出和说明。

不要为凑每日提交新增空文件或重复笔记。有新的问题、验证或结论时，再把经验追加到学习记录。完整代码留在实现文件中，日志引用代码和 commit。

## 基础验收与后续衔接

基础验收看五件事：

1. 能说明 shape、axis、广播，以及 view/copy 的影响。
2. 能读取、清洗、合并和分组；数量变化与统计结果可核对。
3. 能解释图表回答的问题、单位和数据范围。
4. 换一份同结构数据，能够按说明从头重跑，错误可定位。
5. 能提供自己的代码、实际输出和解释。

通过后进入小型 GPT：张量与训练循环 → 文本窗口和嵌入 → 因果/多头注意力与模型 → 训练验证 → 生成 → checkpoint/resume → 受控对照与复盘。

先划分训练和验证数据，再用训练部分拟合填补或标准化参数；训练日志分析继续复用前期成果。MacBook 与 5080 各建自己的环境，代码通过 GitHub 同步。

后期范围取决于基础实际用时。12 月 15 日记录完成、未完成和掌握依据；不因日期到了强行跳过基础，不把完整工业大模型训练列为本期承诺。
