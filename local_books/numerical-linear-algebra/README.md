## 原翻译流程

1. 先用 `pdftotext` 得到候选文本，再回看对应 PDF 原页；上下标、共轭转置、帽号、求和上下限、矩阵形状和不等式不能凭 OCR 猜测。
2. 每讲完成后，从读者角度补足首次出现的术语、维数条件和段落衔接，但不改变原书命题、证明和算法含义。
3. 插图保留原书图号和引用。可可靠裁切的扫描页线稿直接保存为本地 PNG；无法可靠提取的图在 `/tmp` 等临时目录中用 Matplotlib 重绘，工作区只保留最终 PNG/SVG，不保留绘图脚本。若图中文字是数学记号则原样保留，并在中文图注中解释。
4. LaTeX 独立编译、Markdown 公式检查和图片路径检查均通过后，才把该讲标记为完成。

## LaTeX 编译环境

现有独立 LaTeX 文件为第 6–40 讲，使用 XeLaTeX、`ctexart` 及 `Songti SC`、`PingFang SC` 等 macOS 字体。图片路径相对于 `latex/` 目录；重新编译时从该目录运行。其他系统需要提供对应字体，或将字体设置改为当地可用的中文字体。第 1–5 讲没有独立 LaTeX 源文件，可直接阅读 Markdown 或已生成的分讲 PDF。
