## 1. 列表、字典和嵌套结构

列表保存一组元素，字典保存键值对：

```python
scores = [60, 80, 80, 100]             # 列表
case = {"scores": scores, "threshold": 80}  # 字典
```

在 `"threshold": 80` 中，`"threshold"` 是键，`80` 是值。一个键对应一个值，这个值也可以是列表或另一个字典。

本题使用的是**嵌套字典，里面包含分数列表**：

```python
cases = {
    "scores1": {"scores": [60, 80, 80, 100], "threshold": 80},
    "scores2": {"scores": [60, 80, 80], "threshold": 80},
}
```

逐层取值：

```python
case = cases["scores2"]  # 得到第二组的小字典
case["scores"]          # 得到 [60, 80, 80]
case["threshold"]       # 得到 80
```

也可以连着写 `cases["scores2"]["scores"]`。这一句只取出数据，不会按阈值筛选。

真正的嵌套列表形如 `[[60, 80], [90, 100]]`，其中元素本身是列表。本题用字典的键来标识各组和各字段。

## 2. `len()` 数什么

`len()` 的含义取决于传入的对象：列表数元素，字典数键值对，下面的字符串示例数其中的字符。

| 表达式 | 结果 | 原因 |
|---|---:|---|
| `len([100, 8, 60])` | 3 | 三个元素，数字的位数不影响结果 |
| `len([92, 88])` | 2 | 两个数字元素 |
| `len("[92, 88]")` | 8 | 引号使它成为字符串，括号、逗号、空格也算字符 |
| `len([0])` | 1 | 有一个元素，这个元素是零 |
| `len([])` | 0 | 没有元素 |
| `len({"scores": [80], "threshold": 80})` | 2 | 两个键值对 |

C 字符串通常使用 `\0` 标记结束，`strlen()` 遇到第一个 `\0` 就停止。Python 使用字符串时无需手动添加结束标记，显式写入的 `\0` 也计入长度：

```python
len("ab")     # 2
len("a\0b")  # 3，b 仍属于字符串
```

## 3. 遍历字典中的每组案例

```python
for name in cases:
    case = cases[name]
    result = summarize_scores(case["scores"], case["threshold"])
    print(result)
```

- `for name in cases` 每轮取得一个键，例如 `"scores1"`、`"scores2"`。
- `cases[name]` 取得当前键对应的小字典。
- 从小字典中取出列表和阈值，传给同一个函数。
- 循环体统一缩进四个空格；缩进内的语句对每组重复执行。

当前完整代码有四组案例。统计函数处理每组内部的分数，外层循环负责逐组调用。

## 4. 函数参数、`return` 与 `print`

```python
result = summarize_scores(case["scores"], case["threshold"])
```

调用时，第一个值交给参数 `scores`，第二个值交给参数 `threshold`。函数用 `return` 把统计字典交回调用处，再由变量 `result` 接住。

- `return`：结束当前函数调用，并交回一个值，供后续代码使用。
- `print`：把内容显示出来；`print()` 本身的返回值是 `None`。

要先给 `result` 赋值，再写 `result["count"]` 等取值表达式。直接使用尚未定义的 `result` 会报 `NameError`。

最终结果字典的四个键是：

| 键 | 含义 |
|---|---|
| `count` | 分数列表的元素个数 |
| `mean` | 平均分；空列表时为 `None` |
| `above` | 严格大于阈值的分数列表 |
| `above_count` | 筛选结果的元素个数 |

## 5. 列表推导式与严格大于

```python
above = [n for n in scores if n > threshold]
```

可以读成：“依次取出 `scores` 中的每个 `n`，将满足 `n > threshold` 的 `n` 放进新列表。”

阈值为 `80` 时，`80` 不入选，`100` 入选。`>` 表示严格大于，`>=` 才包含等于。

筛选后直接使用 `len(above)` 统计人数，无需再写一遍相同的筛选。列表推导式创建新列表；这里没有修改原始 `scores`。

## 6. f-string、`.2f` 与换行

```python
print(f"平均分：{result['mean']:.2f}")
```

- 字符串前的 `f` 表示可以在 `{}` 中嵌入表达式。
- `result['mean']` 从结果字典中取出平均分。
- `:` 引出格式说明，`.2f` 表示按定点小数格式显示两位小数。

```python
x = 75.4
print(f"{x:.2f}")  # 显示 75.40
print(x)           # 仍显示 75.4
```

格式化改变显示文本，不改变变量本身的数值。本题第二组的平均分约为 `73.33333333333333`，格式化后显示 `73.33`。

每个 `print()` 默认在末尾换行；字符串内部需要换行时使用 `\n`：

```python
print("第一行\n第二行")
print()  # 单独输出一个空行
```

本题的 `print(f"\n{name} 的统计结果：")` 会在每组标题前先换行，使各组输出分开。

## 7. 空列表与 `None`

空列表 `[]` 的长度为零，直接计算 `sum(scores) / len(scores)` 会除以零，产生 `ZeroDivisionError`。

本题约定空列表没有可计算的平均分，返回 `None`：

```python
count = len(scores)
if count == 0:
    mean = None
else:
    mean = sum(scores) / count
```

`[]` 和 `[0]` 不同：前者没有分数，后者有一个零分。对应平均值分别是 `None` 和 `0.0`。

输出时也要处理这个约定。`None` 不能直接使用 `.2f`：

```python
if result["mean"] is None:
    print("平均分：无数据")
else:
    print(f"平均分：{result['mean']:.2f}")
```
